## 설정과 명부 화면

분리열 입력에서 학년이 생략되면 수업 공통 학년을 사용합니다. 학년이 있으면 공통 학년과 일치해야 합니다. 합쳐진 학번은 원문을 문자열로 보존하며 예를 들어 `20105`를 `2학년 1반 5번`으로 해석한 결과를 미리보기로 제시합니다. 모든 학교의 학번이 5자리라고 단정하지 않습니다. 자릿수 해석이 불명확하면 열 대응·분할 규칙 또는 개별 값을 수정한 뒤 적용하도록 합니다.

미리보기는 추가·유지·제외·정보변경을 구분합니다. 잘못된 학년, 누락된 반·번호, 중복된 동일 학생은 행별로 표시하고 적용을 차단합니다. 다른 반의 같은 번호는 정상입니다. 파일 읽기 실패·취소·검증 실패는 기존 명부를 변경하지 않습니다.

보고서는 `subject_teacher/docs/2026-09-10-mixed-class-validation.json`에 구현 후 작성합니다. 최소 필드는 status(pending/pass/fail), checkedAt, desktopVersion, mobileVersion, checks이며 checks는 distinctStudents, reload, filterPersistence, neisSavedRows, idempotency, legacyClass의 각각에 통과 여부와 학생 식별정보를 제거한 근거를 갖습니다. 실제 검증 전 status는 pending이어야 합니다. 실명·학교명·실제 학번·화면 덤프·토큰은 커밋하지 않습니다.

자동 검사만 통과하고 실제 NEIS 검증이 남으면 `구현 완료, 실제 연동 검증 대기`로 보고합니다. 전체 기능 완료는 자동 검사와 수동 완료 사례를 모두 통과했을 때만 판정합니다.
