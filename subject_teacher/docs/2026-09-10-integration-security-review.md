# 체크온 작업 통합·개인정보·보안 점검

점검일: 2026-09-10

## 결론

참조 작업 `깃허브 레포 확인`(01a03c59-c5ce-75a0-bd09-37ec7d72a361)을 조회하고, 현재 공용 체크아웃의 혼합수업 구현 보고서·실제 코드·테스트를 대조했다. 모바일 UX·자동 로그인·Drive 충돌 방지 작업과 혼합수업 작업이 함께 존재하며, 현재 검증 범위에서 기능 충돌은 발견하지 못했다. 최근 참조 작업의 일부 턴은 조회 결과에 본문이 없어 세부 변경 판단에는 로컬 소스와 구현 보고서를 사용했다.

소스 통합과 배포 상태는 별개다. 기존 데스크톱 1.0.8 설치본은 혼합수업 추가 전이며 모바일에는 이후 작업이 반영되어 있다. 이번 점검의 보완은 로컬 소스에만 반영했고 커밋·푸시·신규 설치본 제작·운영 배포는 수행하지 않았다. 기존의 여러 미커밋 변경을 유지했다.

## 이번 보완

- Drive 파일 접근 전 Google Drive 계정 식별자를 확인하고, 로컬 자료와 다른 계정이면 접근·자동 전송을 차단한다. 이메일이나 이름 대신 permissionId만 요청한다. 이전 버전 자료는 최초 한 번 기존 계정 확인이 필요하다. 확인 화면에서도 열린 출결 편집기를 유지한다.
- 로그아웃 전 미전송 출결을 검사하고 보존한다. 전송이 끝났으면 로컬 대기열·캐시·계정 연결 정보·암호화 열쇠를 하나의 저장소 트랜잭션에서 삭제한다. 취소된 계정 확인 응답을 다시 적용하지 않는다.
- 일반 학생 명부도 Drive 쓰기 직전에 이름을 제거한다. 혼합 명부는 기존 이름 제거 경로를 유지한다. 자유 입력 메모에 사용자가 직접 기입하는 개인정보까지 자동 식별·제거하는 기능은 아니다.
- 모바일에도 PC와 동일하게 혼합수업 명부의 현재 버전/이력 일치, 학생 ID의 과거 소속 불변, 수업 ID 및 수업 중복 검증을 추가했다. 변경된 검증에 맞게 기존 테스트의 명부 이력 fixture를 정상 형태로 수정했다.
- OAuth state 비교에서 UTF-8 바이트 길이가 다른 입력을 정상 거부하도록 수정했다.
- MIME 추측 방지, referrer 전송 제한, 외부 프레임 삽입 방지, 카메라 외 불필요한 기기 권한 제한 헤더를 추가했다. Google 로그인과 QR 카메라에 대한 운영 응답 검증은 배포 후 필요하다.
- PyInstaller가 웹 OAuth 설정이나 알 수 없는 형태의 자격증명 파일을 포함하려 하면 빌드를 거부한다. 설치형 OAuth 공개 클라이언트 설정만 허용한다.
- 개인정보 안내를 `subject_teacher_pwa/src/privacy-policy.json`으로 통합했다. 앱 화면은 직접 읽고 HTML·Markdown은 생성한다. 빌드 시 세 안내의 일치 여부를 검사한다.
- 학번 기반 출결도 개인정보라는 점, 모바일 캐시·대기열의 별도 앱 암호화 부재, 혼합 명부 이력, 로그인 쿠키 최대 기간, 로그아웃과 암호화 연결 해제 차이, 제거 후 남는 PC 자료를 안내에 반영했다. 법적 준수 완료나 모든 제3자 접근 불가능을 보장하는 표현을 제거했다.

## 공개 배포 전 남은 확인

1. 혼합수업을 포함한 PC와 모바일 대응 버전에서 같은 번호·다른 원소속 반 학생의 실제 NEIS 저장·재조회 확인. 실기기 증거 관련 skipped 검사는 미완료로 유지한다.
2. 삼성인터넷 설치형 웹앱에서 최초 로그인, 장시간 미사용 후 자동 갱신, 기존 계정 확인, 다른 계정 전환 차단, 오프라인 재전송 및 로그아웃 삭제 확인. Google 실제 사용자 동의와 장시간 모바일 E2E는 자동 테스트만으로 완료 처리하지 않는다.
3. 운영자 표시, 학교의 적법한 처리 근거와 권한, 실제 인프라 처리 지역·접속 로그 보유기간·국외 이전 관련 안내 확정. 현재 방침은 미확정 항목을 명시한 배포 준비안이다.
4. 일반 수업의 과거 평문 호환 경로가 남아 있으므로 운영 Drive의 암호화 전환 완료와 모든 대상 파일 상태를 확인한다. 혼합 자료는 코드에서 암호화를 강제한다.
5. 새 데스크톱 설치본 제작 후 설치·실행·실제 Google 연결 확인. 이전 1.0.8의 실행 검증을 신규 소스 빌드 검증으로 간주하지 않는다.
