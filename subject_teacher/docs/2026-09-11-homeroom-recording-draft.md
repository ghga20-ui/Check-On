# 담임 기록 첫 버전 협의안

> 2026-09-14: 시안 승인 후 첫 버전을 구현했습니다. 아래는 이전 협의 기록이며 최신 범위·제약은 `2026-09-14-homeroom-recording.md`를 따릅니다.

확정: 교과 출결과 담임 출결 메뉴를 항상 함께 표시합니다. PC 왼쪽, 모바일 하단에 배치합니다. 계정·연결·학교 정보는 공유합니다.

## 첫 화면 제안 — 아직 협의 중

우리 반 전체 명단을 기본으로 제안합니다. 날짜 이동과 ‘변동 학생만’ 필터를 함께 두어 전체 확인과 변경 내역 확인을 오갈 수 있습니다.

- PC: 왼쪽 날짜·우리 반 명단, 학생 선택 시 오른쪽에 기록 패널.
- 모바일: 위에 날짜, 아래에 학생 번호 목록. 학생을 누르면 아래에서 기록 패널이 열림.
- 담임 학급은 일반 학급 명단에서 선택. 이름은 PC에만 표시하고 모바일은 번호 중심으로 유지.
- 학생을 고르면 그 날짜의 기존 기록을 먼저 보여 줌. 같은 날 두 번 기록하더라도 앞 기록을 조용히 덮어쓰지 않음.

## 기록 패널 제안 — 사용자와 다음 단계에서 확정

| 항목 | 제안 |
|---|---|
| 출결 종류 | 결석 · 지각 · 조퇴 · 결과 |
| 구분 | 질병 · 미인정 · 기타 · 출석인정 |
| 범위 | 종류에 맞는 교시 또는 하루. 임의로 1교시를 채우지 않음 |
| 사유 | 사유 구분과 별개의 자유 입력란. 담임 일일출결에 옮겨 적을 문장을 출결 건마다 보관하고 내역에서도 표시. 필수 여부·길이 제한은 실제 나이스 화면 확인 후 결정 |
| 수정 | 기존 기록 수정·취소, 저장 성공 전 초안 보존 |

교과에서 기록한 결과를 담임 결석으로 자동 변환하지 않습니다. 첫 단계는 담임 기록과 일별·학생별 조회이며 나이스 일일출결 입력은 실제 화면 확인 후 별도 연결합니다.

## 구분해야 할 상태

- 기록 없음: 출석 여부 미확인.
- 교사가 확인한 전원 출석: 확인된 기록.
- 출결 변동: 종류·구분·범위를 표시.

담임 데이터는 교과 기록과 별도 파일·스키마로 두며, 현재 이 문서는 협의 초안입니다. 실제 담임 저장 기능은 아직 연결하지 않았습니다.

## 시안 협의 후 추가 요구

- 사용자 확인: 담임 일일출결에는 사유를 적으므로 별도 텍스트 입력을 지원해야 합니다. 질병·미인정 등 구분만으로 대체하지 않습니다.
- 시안은 출결 건별 사유 입력·수정, A/B 내역의 사유 표시, 여러 학생에게 동일 사유 적용을 지원합니다. 빠른 종류 선택으로 사유 문장을 임의 생성하지 않습니다.
- 같은 날 지각과 조퇴는 각각 기록·사유를 보관합니다. 현재는 시안 내부 동작이며 실제 저장과 나이스 반영은 미구현입니다.
